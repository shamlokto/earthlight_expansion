SATO'S HARVEST — OFFLINE COPY
==============================

Play with no internet:

  Windows : double-click  "Play Sato's Harvest (Windows).bat"
            (if Windows warns about a file from the internet: More info, then Run anyway)
  Mac     : double-click  "Play Sato's Harvest (Mac).command"
            (the first time, macOS may say it cannot check the file: right-click it, choose Open, then Open again)
  Linux   : run  ./play.sh

A small window opens and the game starts in your browser at http://localhost:8777/farm.html.
Keep that window open while you play; close it when you are done.

Why not just open farm.html? Browsers block games that load their own files straight from the disk,
so the launcher runs a tiny web server that only this computer can reach.

Your saves
----------
The offline copy keeps its own saves in this browser (always at the same address, so they last).
To move a farm between the offline copy and the online game (https://shamlokto.github.io/earthlight_expansion/farm.html):
  Menu > Export save  in one,  then  Import save  on the title screen of the other.

Newer versions: download the zip again from the game's title screen ("Download the game (.zip)")
and replace this folder. Export your save first, then import it into the new copy.
