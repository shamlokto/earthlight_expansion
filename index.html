      Terrain classes

      Map value → terrain id (map header byte 80+v) → type ($01:CE7E) → class ($01:CECE). Movement and combat only use the class. Class 10 (blocked) is also written as the out-of-bounds frame around every map.

      Movement cost $01:CF12 · rows = terrain class, columns = unit category

      Each hex costs this many movement points; — impassable; stop entering uses all remaining movement. Enemy zone of control also forces a stop.
